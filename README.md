# hjkland 🎈

vim のカーソルを乗りこなす遊園地。vim が苦手な人が、楽しく・飽きずに・継続的に vim 操作を鍛えられるブラウザゲーム。

- **レッスン**: 新しい vim コマンドを解説+ブラウザ内演習で学ぶ(クリアでコマンド解放)
- **ドリル**: 解放済みコマンドのお題を反復。キーストローク数でスコアリング
- **デイリーチャレンジ**: 毎日1問の日替わりお題とストリークで習慣化
- **弱点分析**: 苦手コマンドを検出してドリルに再出題

**プレイはこちら → https://kensusai.github.io/hjkland/** (進捗はブラウザ内に保存されます)

## 進捗のバックアップ

進捗はブラウザの IndexedDB にだけ保存されます。**ブラウザは長期間アクセスがないと保存データを消すことがある**(特に Safari/iOS は約7日)ため、どちらかのバックアップを推奨します。

### クラウドバックアップ(推奨・自動)

自分の GitHub アカウントの private gist に自動保存します(詳細設計は `docs/adr/0008-optional-gist-backup.md`)。

1. GitHub でトークンを作る: **Settings → Developer settings → Personal access tokens** で、**gist 権限だけ**を付けたトークンを発行する
2. アプリのホーム画面下部「☁️ クラウドバックアップ」にトークンを貼って有効化し、「今すぐバックアップ」を押す
3. 以降は進捗が変わるたびに自動でプッシュされる。gist は https://gist.github.com に「hjkland progress backup」として作られる

復元は同パネルの「復元」ボタンから。ブラウザにデータが無い状態で起動した場合は、バックアップから自動復元されます。トークンはこの端末の localStorage にだけ保存され、GitHub 以外には送信されません。

### 手動エクスポート/インポート

ホーム画面最下部の「エクスポート」で進捗一式を JSON ファイルとして保存できます。復元は「インポート」に同じファイルを渡すだけです(現在の進捗は全置換されます)。

## 開発

```sh
npm install     # 依存のインストール
npm run dev     # 開発サーバー (http://localhost:5173)
npm run check   # CI と同じ全チェック(lint → format → 型 → テスト → ビルド)
npm run e2e     # 実ブラウザのスモークテスト
```
